# 提示词编写模板

> 本目录（`临时文件/`）用来写**提示词草稿、临时 SQL、临时说明**。
> 这里的文件都是「过程稿」，可以随手删。
> 一旦提示词最终产生脚本 / 输出，请把它们移到对应的 `对话文件夹/<本次对话>/` 下。

---

## 一次数据处理请求的提示词骨架

```text
【任务背景】
我要从数据库里取数 / 清洗 / 对比 / 同步 ……
涉及表：<表名1>、<表名2>
大致数据量：<行数估计>
时间范围：<起始 ~ 截止>

【输入】
- 数据源：1配置文件/ 下的哪个 ini 配置文件（可写关键字，如 本地 / 为知V2-供应链）
- 关键字段：<字段说明>

【处理逻辑】
1. ……
2. ……
3. ……

【期望输出】
- 输出格式：CSV / Excel / JSON / 直接写回数据库
- 输出位置：对话文件夹/<本次对话>/输出数据/
- 字段：<列出最终输出的列>

【约束】
- 只读 / 可写
- 是否需要脱敏
- 性能 / 内存限制

【写操作安全】（涉及 UPDATE / DELETE / INSERT INTO ... SELECT 时必填）
- 影响范围估计：<多少行>
- 备份策略：CSV 快照到 备份/<表名>_before_<时间戳>.csv
- 回滚方式：执行 备份/<表名>_rollback.sql
- dry-run：先跑一次 SELECT COUNT(*) 确认影响行数
```
